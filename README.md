# TradeFlow - Static Trading Website

## Overview

TradeFlow is a static trading-themed frontend demonstration built using HTML, CSS, and vanilla JavaScript. It offers a modern financial UI with market cards, company information, and a contact form without any backend or API integration.

## Features

- Responsive design
- Trading-themed UI
- Market overview
- About page
- Contact page
- Frontend form validation
- Mobile navigation
- Responsive layout
- No backend
- No API

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Running Locally

This is a static website, so you can open `index.html` directly in a browser to view the site.

Optionally, you can serve the project with a local static server if you prefer:

```bash
# example using Python 3
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

This project can be deployed directly to Vercel as a static site. No special configuration is required.

Vercel will provide a default deployment URL once the project is connected.
